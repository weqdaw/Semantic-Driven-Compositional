# 验证

E1测试在`test_e1_features.py`和`test_e1_workflow.py`，覆盖概念余弦不额外归一化、字面C0/C1统计、固定随机方向、概念及冻结错配、Z/E/P与全部派生表示一致性、完整360组、支持内投影平均、缺项／篡改拒绝、保存模型前向复核及生产合成／最终测试阻断。正式E1不因pytest而启动。

第二轮补充消融测试位于`test_ablation_features.py`和`test_ablation_experiment.py`：覆盖重复均值的统计权重、稳定排列／回放、缓存损坏、完整180组流程、同支持集合内扰动平均、配对指标复算、篡改拒绝和生产入口身份／阶段保护。仍只在pytest临时目录使用合成特征，不启动真实补充实验。

执行`.venv/Scripts/python.exe -m pytest -q`。37项测试覆盖官方标注缺失/冲突、安全路径、内容验证别名、冻结清单、角色与内容互斥、嵌套抽样、16帧边界与实际AVI解码、常量帧数值稳定、损坏缓存与跨进程身份、岭损失尺度和截距、固定列/平局、完整运行、缺种子/混合条件/损坏预测拒绝，以及非官方特征的生产入口拒绝和报告标识。

合成数据写入pytest临时目录，不作为真实实验。真实验证另有10段支持池冒烟、350段训练视频CLIP编码、30组开发及完整重复、1段真实视频新进程再编码。最终测试未用于功能验证。
