# E0后续实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans when implementation is explicitly requested. 本轮仅保存计划，不执行任何实现。用户要求不写代码，本文只列文件、输入输出和验收行为。

**Goal:** 实现可复现的HMDB51固定五类1／3／5-shot冻结视觉开发基线。

**Architecture:** 外部视频与官方标注形成受控清单；冻结编码和缓存与标签训练分离；支持抽样、岭分类及报告按唯一运行身份衔接。

**Tech Stack:** 独立Python 3.12环境；张量编码、固定视频后端、NumPy、分类指标与YAML工具，实际版本在环境核验后锁定。

**Spec:** [骨架设计](../specs/2026-11-16-e0-scaffold-design.md)、[实验说明](../../EXPERIMENT_GUIDE.md)、[数据契约](../../DATA_CONTRACTS.md)。

## 全局约束

外部数据只读；官方split缺失时阻塞；固定类序与种子；完整视频为shot；骨干冻结；先开发后封存测试；真实产物带哈希；不把当前空脚本当成功实现。

## 审查重点

1. 官方列表和本地版本不对应。
2. 非支持标签或测试信息进入模型选择。
3. 短视频、损坏视频、帧边界或重复源导致样本虚增。
4. 缓存跨不同权重／预处理误复用。
5. 多类得分列、岭损失尺度或种子聚合错误。

## 任务1：环境、配置与输入审计

- 文件：config.py、inventory.py、video_io.py、provenance.py、scripts/01_audit_dataset.py。
- 输入：路径配置、官方split、视频元数据。
- 输出：结构化审计结果、五类官方训练视频的固定后端解码及≥16有效帧资格清单、阻塞状态；最终测试仅核对列表／文件身份。
- [ ] 编写缺split、缺视频、标签冲突、越界路径的失败案例。
- [ ] 实现只读核验、配置约束及训练视频资格审计，先验证16帧索引边界、短视频和解码失败，不伪造官方身份。
- [ ] 验证异常输入有明确失败和清单，锁定可用依赖版本。

## 任务2：固定清单与支持抽样

- 文件：manifest.py、sampling.py、scripts/02_build_manifests.py、scripts/04_sample_support_sets.py。
- 输入：任务1已完成解码资格审计的有效官方训练视频、官方测试身份清单、固定类序与种子。
- 输出：manifest、类别映射、开发／支持候选／封存测试名单、按种子K的支持记录。
- [ ] 先验证互斥、唯一ID、0标签排除、数量不足失败、1⊂3⊂5与重复运行相同。
- [ ] 仅从有效训练集合实施既定排序、PCG64抽样及明确计数；冻结后新失败阻塞，统一修订协议，禁止按K或种子补样。
- [ ] 验证不读取官方测试内容选择开发或支持。

## 任务3：视频采样、冻结编码与缓存

- 文件：复用任务1的video_io.py，新增clip_features.py、feature_cache.py、scripts/03_extract_features.py。
- 输入：允许阶段的视频清单、检查点与预处理身份。
- 输出：带来源的逐视频特征缓存及排除记录。
- [ ] 先验证16帧索引边界、短视频、解码失败、归一化零向量和缓存不匹配。
- [ ] 实现原生预处理、冻结评估模式、均值与总体标准差。
- [ ] 在官方训练中的极小样本上核验形状、有限值与权重不变，暂不提取测试特征。

## 任务4：多输出岭与开发评价

- [ ] 先用小型合成数据验证截距不惩罚、λ尺度、列映射和argmax规则。
- [ ] 实现开发评价，默认拒绝final_test阶段。
- [ ] 验证仅支持标签参与拟合，固定输入输出可复现。
