# E2.0-R2 固定人体目标与ROI实验计划

2026-11-24，用户授权新增代码并完成实验；沿用已授权AI预审核，未获得独立人类真值。实施并验证后执行固定60帧的主对照，不替换帧或视频，不把多裁剪计作新shot。视频内有效帧重采样是独立后续条件，不混入本轮ROI对照。

固定继承E20R主队列20视频/20保守来源组/60原图、六概念与原文本E。旧包及原源码保持完整，使用旧包的已核验源码快照在独立Python -I -B进程校验，解决新增模块改变全局代码身份的问题；不修改旧SHA。

先逐帧审核person_status、固定target_id、可见人体框、双肩/双手/腰部可见性、人物高度和证据。每帧原图选择可见人体面积最大者，并列取最左，目标ID绑定到具体帧并跨三输入固定，不随概念或得分切换；无法明确指定则标ambiguous。不同帧不声称已完成身份追踪，避免将电影切镜中的不同人物误称同一轨迹。只框可见人体，不补出画外肢体；AI框是探索性人工框替代，不是独立真实标注或自动部署能力。

从12个不同视频固定抽12帧作规则校准子集，AI校准明确标AI，人工校准仍待办。全60帧审核后冻结目标；概念标签与目标审核独立填写。有效人体帧事前规则：目标可确定、两肩/两手/腰部均明确可见、原图人物框高度至少80像素。该规则为本轮工程约定，不是通用标准，不用于删除主队列样本。

条件A原生中心裁剪224；B全图加边224；C目标框向四周各扩10%框宽高、裁至原图边界，再同一加边224。保持同一冻结CLIP参数/原生归一化和文本向量；三条件分别编码。目标框引入额外定位监督，同时改变背景和人物尺度，C的收益仅解释为人物聚焦整体作用。目标参考框叠加图只供审核，模型输入不能含框线。

阶段：check→prepare→targets.csv→freeze-targets→native360→letterbox360→roi360→encode→summarize。每个概念都保留60行；缺ROI的概念行须明确填uncertain，编码使用有效掩码、无效向量NaN及空分数，不用零向量/零分数填补。包中模板、框、身份、像素、代码、模型、分数和冻结顺序可核验。报告分别给全60帧覆盖、目标/有效人体帧保留率、可判定子集排序、固定错配及同帧/同目标/同标签的三种配对；ROI不可用行不参与AUROC。

沿用来源聚类bootstrap1000次，最低5来源/800有效；门槛同一输入至少3概念：可判定≥.70、5正5负各3视频、AUROC≥.70且较固定错配≥.05；另需独立人工审核链。AI执行不能通过完整门槛。不训练参数、不编码新文本、不新增动作分类或溺水性能结论，final_test封存。

新增模块：e20r2_protocol、e20r2_source、e20r2_workflow、e20r2_reporting、e20r2_cli，脚本17及固定YAML；测试数值/框与目标规范/缺ROI/完整合成流程/源与像素与分数损坏/生产限制。运行后保存报告、可复核AI标签/框、空白人工表及执行验证。
